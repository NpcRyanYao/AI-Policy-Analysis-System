# 已知限制、未完成事项与下一阶段

## 已知限制（当前版本可验收但需知情）

1. **政府官网反爬**：列表页结构不稳定，实时抓取经常超时或得到导航页。系统会记录错误并回退快照，**不会用空结果覆盖已有数据**。演示主路径是快照 + URL/正文补录。
2. **快照正文是公开摘录**：足以支撑结构化解析、合规摘要和来源核验；完整条文请点击 `original_url`。个别地方政策链接若官网改版，以中国政府网 / 网信办国家层面链接为优先核验对象。
3. **无大模型 Key 时使用规则引擎**：基于「应当/不得/鼓励」等句式与关键词分类，稳定性高于随机 LLM，但归纳深度有限。配置豆包 Ark 后同一接口可切换。
4. **检索**：jieba + FTS5 对短词和同义词召回一般，未做同义词词典。
5. **用户体系**：公开只读 + 可选管理员令牌，收藏为单库全局，不是多租户。
6. **邮件推送**：SMTP 未配置时仅站内日报。
7. **PDF 中文**：使用 ReportLab CID 字体 `STSong-Light`，版式简单。
8. **地方站点适配器**：北上广浙以注册表 + 补录为主，未针对每个 CMS 写死选择器。
